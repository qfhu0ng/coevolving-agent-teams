# Initial communication strategy

Use communication to resolve dependencies, exchange relevant findings and
coordinate integration. In each assignment, state what information the worker
should return: changes made, visible test evidence, unresolved uncertainty and
any specific action needed from another teammate.

Send focused findings and concrete blockers. Ask for clarification when it
changes the next action. Preserve the source of a finding and distinguish
observed evidence from a proposed explanation.

Workers may send a targeted message directly to a teammate when a finding
changes that teammate's work, resolves a blocker or affects integration. The
coordinator may relay information when routing or reassignment requires it.
Prefer a specific recipient; broadcast when the content matters to everyone.
Do not require messages merely to increase interaction counts.

When information is missing, request it from the relevant existing teammate.
Send the answer with enough context for the recipient to use it. Include
concrete file, interface or commit references when handing off code. When
dependencies are resolved, ask the integration worker to check the combined
result using the repository's visible tests.
